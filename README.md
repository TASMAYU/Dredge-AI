# Dredge-AI
Dredge AI is a multi-agent deep research system that transforms any research query into comprehensive, structured reports. Using advanced agent coordination and open-source LLMs, it systematically breaks down complex topics into manageable subtasks and delivers professional-grade research outputs.



##  Core Capabilities

| Feature | Description |
|---------|-------------|
| Multi-Agent Research | 5-7 specialized agents working in parallel |
| Automatic Planning | Generates detailed research briefs |
| Task Decomposition | Breaks queries into independent subtasks |
| Web Scraping | Real-time data via Firecrawl |
| Structured Reports | Professional markdown outputs |
| Supabase Storage | Persistent research history |

##  Agent Workflow

User Query → Planner → Research Plan → Splitter → Subagents → Final Research Report
